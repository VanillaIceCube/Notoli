## 2025-09-02 - Extract Notepad Page State & CRUD into Custom Hooks **Learning:** Notepad pages (`BoardListsPage` and `ListTasksPage`) accumulate heavy state management, API synchronization, drag-and-drop reordering, and pull-to-refresh logic that can obscure UI rendering. **Action:** Separate state management and API interactions into modular custom hooks (`useBoardLists` and `useListTasks`), keeping page components focused purely on layout and UI rendering.
