## 2026-03-31 - Backend Test Suite Execution Speed **Learning:** In Django, default PBKDF2 password hashing during unit tests causes test suite execution to take > 400s and time out. Configuring `MD5PasswordHasher` when `IS_TESTING` is True reduces test execution time to under 15 seconds. Additionally, setting a default `SECRET_KEY` of at least 32 bytes prevents JWT HMAC key length warnings, and creating `STATIC_ROOT` during testing prevents WhiteNoise `UserWarning`s. **Action:** Ensure `backend/app/settings.py` keeps test-environment settings (`MD5PasswordHasher`, 32+ byte default `SECRET_KEY`, and `STATIC_ROOT` initialization) intact when making settings or test framework updates.
