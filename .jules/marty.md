## 2026-03-31 - Accelerate Backend Test Execution via Test Password Hasher **Learning:** Django default password hashers (PBKDF2/Argon2) significantly slow down unit test execution (>400s timeout on 123 tests) when tests frequently create users or authenticate. Overriding `PASSWORD_HASHERS` with `MD5PasswordHasher` during test runs (`"test" in sys.argv` or `DJANGO_TESTING == "1"`) reduces test runtime to under 16 seconds without impacting production security settings. **Action:** Ensure any custom test runners or test settings maintain fast password hashing to keep local and CI verification fast and responsive.
